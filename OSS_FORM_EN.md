## Why does this repository qualify?

This MIT CLI helps OSS maintainers use Codex/OpenAI APIs constructively: Keep-a-Changelog release-note prompts from git history, PR review checklists (security/tests/docs/breaking changes/AI hygiene), and a doctor env check. Offline --dry-run first; secrets only via OPENAI_API_KEY. Unofficial, not affiliated with OpenAI. Real maintainer workflows, not a demo toy.

## How will you use API credits?

Credits will fund real maintainer workflows in this kit: drafting release notes from git logs (after dry-run prompt iteration), optional API-assisted PR review summaries, and CI/docs examples. Prefer dry-run to refine prompts before spending tokens; no key logging; budget for maintainer demos and contributor docs only—not bulk scraping or unrelated apps.
